# PyTorch CNN Project

This project implements a simple Convolutional Neural Network (CNN) using PyTorch. The CNN is designed for basic image classification tasks and serves as an introductory example for understanding CNNs in PyTorch.

## Project Structure

```
pytorch-cnn-project
├── src
│   ├── main.py          # Entry point of the application
│   └── models
│       └── simple_cnn.py # Defines the SimpleCNN class
├── requirements.txt     # Lists project dependencies
├── .gitignore           # Specifies files to ignore in Git
└── README.md            # Project documentation
```

## Requirements

To run this project, you need to have Python and PyTorch installed. You can install the required packages using the following command:

```
pip install -r requirements.txt
```

## Running the Project

To run the CNN model, execute the following command in your terminal:

```
python src/main.py
```

This will create an instance of the SimpleCNN model and print the number of learnable parameters in the model.
